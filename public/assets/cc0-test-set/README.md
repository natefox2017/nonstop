# Temporary playable-slice character assets

These models are temporary validation art for the portrait vertical slice. They do not set the final production art direction and can be replaced after the HUD and production art direction are reviewed.

The files are from Kay Lousberg's KayKit packs:

- `Knight.glb` and `Barbarian.glb` — [KayKit Adventurers Character Pack 2.0](https://kaylousberg.itch.io/kaykit-adventurers)
- `Rig_Medium_General.glb`, `Rig_Medium_MovementBasic.glb`, and `Rig_Medium_CombatMelee.glb` — [KayKit Character Animations 1.1](https://kaylousberg.itch.io/kaykit-character-animations)

Both packs include the original CC0 license text in this directory. The author states that attribution is optional; attribution is retained here for provenance. These assets are not Nintendo or other third-party game IP.
